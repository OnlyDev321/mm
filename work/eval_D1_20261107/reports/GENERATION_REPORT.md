# D1 평가 1단계 생성 결과

MMMU validation **900문항** 생성과 검증을 완료했다. 파드·로컬 raw 및 실행 기록의 SHA-256이 일치했다.

## 조건과 검증

- E3와 동일한 소스 압축 SHA-256 `f82e35829818953c7b2cb5084831720f62062bb0bad94898835b366d5939ae46`를 사용했다. 생성 소스 `9fe57b1176caa74435d1c739de93e9de96e857df`, 평가 기준 main `016b3cf558e3dd9e366b277f5f871b28092a1379`이며 원본 코드·config·게이트·requirements는 그대로다. config SHA-256은 `a41d4973f753da715b8cf5258913ff075b5de60ffdc014ee4eb58dea17e41ce7`다.
- NVIDIA RTX 4090 1장, 이미지 기본 Python 3.12.3, torch 2.8.0+cu128, vLLM 0.11.0을 사용했다. 설치는 고정 `run_generate.sh`와 같은 경로였고, 병합만 system-site-packages venv와 PEFT 0.17.1로 실행했다.
- 원본 모델 `Qwen/Qwen3-VL-4B-Instruct @ ebb281ec70b05090aa6165b016eac8ec08e71b17`에 adapter `2d4bcce4972b36b6ef49b0b73d46c9d72a3803f43632b6847ae6f4d65e0132e8`를 bf16으로 병합했다. processor/tokenizer는 원본 바이트와 일치했고, 아래 두 가중치 샤드는 A100 학습 후 병합 기록과 정확히 일치했다.
- 전체 환경 게이트 집계는 `{"INFO": 10, "PASS": 46}`다. preflight 900/900, 입력 길이 초과·검증 오류 0건이다. 별도 smoke 3문항은 오류·입력 불일치 0건으로 완료했고, 본 실행은 새 폴더에서 시작했다.
- 900개 고유 ID, 30과목 × 30문항, skip·오류 0건이다. M0 입력·프롬프트 토큰 불일치는 0건이며, D1 입력 토큰 합계는 1,193,656이다. max_model_len 16,384, max_new_tokens 8,192, 샘플링·seed·이미지·프롬프트는 E3와 같다.
