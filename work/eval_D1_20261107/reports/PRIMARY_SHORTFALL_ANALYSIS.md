# D1 1차 기준 미달 분석

고정 M0 `length` 128문항에서 정답은 **46 → 56건**, 획득 24건·상실 14건으로 `net_gain=+10`이었다. 1차 기준 `≥14`에 **4건 미달**했다. 기존 v2 점수와 최종 판정을 유지했다. 아래 원문 분류는 상실 사례를 설명하기 위한 진단이다.

- D1이 정상 종료한 49문항에서 **+9**가 나왔고, D1도 잘린 79문항에서는 **+1**에 그쳤다. 상실 14건 중 9건은 D1도 8,192토큰에서 잘렸다. 정상 종료한 상실 5건은 모두 D1이 기준 답과 다른 답을 명시했다.
- Tech & Engineering은 128문항 중 77문항으로, 획득 12건과 상실 9건이 함께 발생해 순증은 **+3**이었다. 순증이 가장 컸던 분야는 Business(**+5**)였고, 그중 Finance가 **+4**였다.
- 상실 14건의 주분류는 **명시적 답 오류 5건, 파서·Judge 영향 의심 4건, 구분 어려움 5건**이다. 의심 사례에는 M0 정답 인정 근거가 약한 경우도 포함된다. 확인한 원문에서 D1이 기준 답을 명확히 확정했는데 채점만 놓친 사례는 없었다.

## 채점 경로 변화

고정 128문항에서 자동은 M0 18건 → D1 41건, Judge는 110건 → 87건이었다. 이 집합의 Judge 경로는 모두 규칙 미추출이었고 충돌은 없었다.

| M0 → D1 | 전체 문항 | `stop` 획득 / 상실 | `length` 획득 / 상실 | 합계 획득 / 상실 | 순증 |
|---|---:|---:|---:|---:|---:|
| 자동 → 자동 | 13 | 1 / 0 | 0 / 0 | 1 / 0 | +1 |
| 자동 → Judge | 5 | 0 / 1 | 0 / 2 | 0 / 3 | −3 |
| Judge → 자동 | 28 | 9 / 0 | 1 / 1 | 10 / 1 | +9 |
| Judge → Judge | 82 | 4 / 4 | 9 / 6 | 13 / 10 | +3 |

Judge → 자동 28문항 중 10건에서 점수를 얻었지만, 이 경로 전환의 순증을 자동 채점 규칙의 효과로 분리할 수는 없다. 응답 원문도 바뀌었다. 상실 14건에서 D1 최종 상태는 Judge가 유효 오답을 반환한 7건, 자동 오답 1건, 최종 추출 실패 6건이었다. 추출 실패 6건은 Judge의 `Z` 4건과 Judge 응답 자체가 `length`로 끝난 2건이다. 이 두 건은 HTTP/API 실패나 D1 자체의 종료 상태와 구분했다.
