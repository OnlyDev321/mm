# D2' 계획: 2회차 DPO (Iterative DPO)

작성 2026-11-07. 학습 전에 고정하고, 결과를 본 뒤 기준·설정을 바꾸지 않는다. 동작 문제로 바꾸는 경우만 변경 기록에 남긴다.
D1 결과를 본 뒤 정한 다음 실험이다 (보고서에 그렇게 적는다). 방법·설정은 D1과 같고, 바뀌는 것은 응답을 만드는 모델(D1)과 시작 모델(D1)뿐이다.

## 1. 배경과 가설

- D1 (M0 응답 707쌍 DPO): 602/900, 정답→오답 54 / 오답→정답 56으로 하방 방어 성공, length 128→101. 그러나 128문항 net_gain +10으로 1차 불통과 (k0 = 10 수준).
- 해석: 방향은 맞지만 학습 신호가 작았다. D1의 쌍은 M0의 실수라 D1을 거치며 일부 이미 반영됐다.

**가설 D2':** D1 자신의 응답으로 쌍을 다시 만들어 D1에서 한 번 더 DPO 하면 (on-policy 갱신), 기존 정답을 지키면서 M0 length 128문항의 정답이 D1보다 더 늘어난다.

## 2. 비교

| 모델 | 학습 | 비교 목적 |
|---|---|---|
| M0 | 없음 | 판정 기준 (600/900) |
| D1 | M0 응답 707쌍 DPO (M0에서 시작) | 기술 비교 (회차 효과) |
| **D2'** | D1 응답 쌍 DPO (D1에서 시작) | D2' vs M0: 판정 |

## 3. 데이터

| 항목 | 값 |
|---|---|
| 문항 풀 | R1 풀 `data/r1_pool.jsonl` 1,500문항 그대로 |
| 샘플링 모델 | D1 (M0 + D1 adapter `2d4bcce4…` bf16 병합) |
| 샘플링 조건 | R1 3단계와 같음: K=4, vLLM 0.11.0, temperature 0.7, top_p 0.8, top_k 20, presence_penalty 1.5, max_new_tokens 8192, max_model_len 16384, 요청 seed 규칙 동일, `reward_v2` 실시간 보상, RTX 4090 |
| 그룹 | `build_groups.py` 기준 그대로 (표적/유지/제외). 학습 세트 = 섞인 문항 전부 |
| 쌍 규칙 | PLAN_D1 3절과 같음: chosen = 정상 종료 + 보상 1 / rejected 우선순위 잘림 → 정상 종료 오답 → 추출 실패, 문항당 최대 2쌍, 응답 재사용 없음, `random.Random(3407)`, 응답 원문 그대로 |

**사전 규칙 (쌍 수):**
- 쌍 ≥ 300: 그대로 학습한다.
- 쌍 < 300: 학습하지 않고 멈춘다. 다음 안은 "D1으로 기존 1,500문항 + MMFR SFT split pass_rate 0.25~0.5 객관식 새 문제 샘플링"(D2 데이터 확대와 결합)이며, 사용자 확인 후 별도 계획으로 진행한다.
- 이 기준은 샘플링 전에 정한 것이고 결과를 보고 바꾸지 않는다.

## 4. 학습 설정

| 항목 | 값 |
|---|---|
| 시작 모델 | **D1 병합 가중치** (M0 rev `ebb281ec…` + D1 adapter bf16 병합, A100 병합 기록 해시와 일치 확인) |

| 나머지 | `scripts/dpo_config.json`과 같음: ms-swift 3.12.3 `rlhf_type dpo`, sigmoid, β 0.1, rpo_alpha 1.0, lr 5e-6, cosine, warmup 3%, batch 1 × 16, seed 3407, 2 epoch, `expandable_segments:True` |
| max_length | 쌍 최장이 10,240 이하면 10,240 유지. 넘으면 최장 이상 12,288 이하에서 정하고 20 step 메모리 파일럿을 먼저 함. 12,288을 넘으면 멈추고 보고 |

- 최종 모델 = M0 + D1 adapter 병합 → + D2' adapter 병합 (순서 고정, 각 단계 해시 기록).

## 5. 평가·판정

평가는 D1과 같은 절차 (4090, `work/eval_B_20261101/PLAN.md` 2절, v2 채점 + Judge). 판정은 PLAN_D1 6절과 같고 **M0 대비**다.

| 구분 | 기준 |
|---|---|
| 1차 | M0 length 128문항 net_gain ≥ **14** (k0 = 10). 참고로 ≥18 여부 |
| 안전 | 900문항 정확도 하락 ≤ 1.7%p, 그리고 정답→오답 ≤ 오답→정답 (M0 대비) |
| 메커니즘 | length 종료 수 < 128, 방향 전환 과다율 < M0(24.1%) |

- 기술 보고: D1 대비 변화(정확도, 128문항, length, 정답→오답/오답→정답), 처리 경로(자동/Judge), 학습 풀에서 D1 → D2' 정답 수 변화.
